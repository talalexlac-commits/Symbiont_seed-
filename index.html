NOT ANOTHER MODEL

A persistent layer above models, tools and local data.

Models can change. Providers can change. Symbiont Seed is built around the state that should remain: identity, memory, Persona, authority and continuity.

01

Identity

A distinct agent identity can persist across sessions and restarts instead of being recreated as a fresh prompt every time.

02

Memory

Persistent Memory has physically survived a real organism restart and recalled the same stored fact afterwards.

03

Authority

Actions move through typed cognitive and execution contracts. External text is not automatically treated as authority.

04

Continuity

Persistent user state and DATA_ROOT survive normal application lifecycle and a tested uninstall/reinstall path.

PHYSICAL PROOF

It actually installs and runs.

Symbiont Seed has been built into a real Windows installer and physically passed the following lifecycle on the primary Windows development machine:

Install→Cold launch→Normal operation→Shutdown→Uninstall→Preserve DATA_ROOT→Reinstall→Relaunch

Boundary: this physical acceptance has not yet been repeated on an independent clean Machine B. No claim of universal Windows hardware compatibility is made.

LOCAL FIRST

Cloud intelligence is optional infrastructure, not the organism.

Local inference has been physically demonstrated through Ollama with a small local model. The architecture treats the LLM as a replaceable cognitive resource rather than the identity of the system.

Provider abstraction exists, but equal production E2E acceptance is not claimed for every cloud provider.

SECURITY-AWARE ARCHITECTURE

Data is not the same thing as a command.

Symbiont Seed includes typed action contracts and the KOTK diagnostic/evidence layer for provenance, prompt-injection and authority-related analysis.

No claim of independent penetration testing, production security certification or complete prompt-injection resistance is made.
